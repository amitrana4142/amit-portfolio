# Photography gallery

Your photos live here and are listed in `src/data/galleryPhotos.js`.

## Add a new photo

1. Copy the image into this folder.
2. Add the filename to the `filenames` array in `src/data/galleryPhotos.js`.
3. Set `alt` caption text in that file if you want custom labels.

Supported formats: JPG, JPEG, PNG, WebP.
